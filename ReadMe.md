# K&F Car Detailing

A premium car detailing website showcasing professional auto care services including paint correction, ceramic coating, interior restoration, and paint protection.

## Project Structure

```
K-F-Car-Detailing/
├── index.html           # Home page with hero section and service overview
├── services.html        # Complete services catalog with pricing
├── gallery.html         # Visual gallery of detailing work
├── about.html           # About the company and values
├── contact.html         # Booking and contact form
├── style.css            # All styling and responsive design
├── script.js            # Interactive functionality and form handling
├── CNAME                # Domain configuration for GitHub Pages
└── images&videos/       # Media assets
    ├── kflogo.png       # Company logo
    └── [Photo gallery images]
```

## Pages

### Home (index.html)
- Hero section with main call-to-action
- Service highlights strip
- Pricing overview
- Booking form

### Services (services.html)
- Comprehensive service cards (10+ services)
- Three-tier pricing packages (Silver, Gold, Platinum)
- Add-on services section
- Service process steps (Inspection, Correction, Protection)

### Gallery (gallery.html)
- Photo gallery of completed detailing work
- Responsive grid layout with varied image sizes
- 13+ photos showcasing foam washing and cleaning processes

### About (about.html)
- Company story and mission
- Team values
- Service philosophy
- Service offerings summary

### Contact/Booking (contact.html)
- Booking form for appointments
- Vehicle type and service package selection
- Contact preference options
- Contact information display

## Features

- **Responsive Design**: Mobile-first approach, works on all device sizes
- **Modern Typography**: Google Fonts (Inter font family)
- **Clean UI**: Minimalist design with service-focused layout
- **Image Gallery**: Responsive gallery with varying aspect ratios
- **Navigation**: Sticky header with mobile menu toggle
- **Form Handling**: Booking form with vehicle and service options
- **SEO Optimized**: Meta descriptions and semantic HTML

## Responsive Breakpoints

- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px

## File Editing Tips

- **Colors**: Edit CSS variables at the top of `style.css`
- **Content**: Update text in respective HTML files
- **Images**: Replace image paths in src attributes
- **Pricing**: Update service prices in price-card sections
- **Contact Info**: Edit contact form and footer information

## Deployment

Hosted on GitHub Pages using the CNAME file for custom domain configuration.
